# 🤖 AI Email Assistant (n8n Workflow)

This project is an automated email assistant built using n8n and AI.

## 🚀 What it does
- Monitors incoming emails (Gmail)
- Reads email content
- Uses AI to:
  - Understand the email
  - Generate a reply
  - Classify the email into categories
- Creates a draft reply automatically
- Adds labels to emails such as:
  - Spam
  - Promos
  - Meetings
  - Sponsorship
  - Check Later

---

## 🧠 AI Features
- Smart email classification
- Automatic response generation
- Uses external tools:
  - Google Calendar (for availability)
  - Airtable (for goals alignment)

---

## 🛠️ Tools Used
- n8n (workflow automation)
- Gmail API
- AI Agent (LLM)
- Google Calendar API
- Airtable API

---

## 📥 How to use

1. Download the JSON file
2. Import it into n8n
3. Connect your credentials:
   - Gmail
   - AI model (Groq / Gemini / OpenAI)
   - Google Calendar
   - Airtable
4. Activate the workflow

---

## ⚠️ Important Notes
- Credentials are NOT included for security reasons
- You must add your own API keys
- Make sure all integrations are connected before running
